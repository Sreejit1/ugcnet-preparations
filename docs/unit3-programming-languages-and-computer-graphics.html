Unit III – Programming Languages and Computer Graphics

UGC NET Computer Science and Applications – Paper II

This unit covers programming language concepts, C, C++, object-oriented programming, web programming, and computer graphics.

Part A – Programming Languages

1. Programming Language Concepts

A programming language is a formal language used to write instructions that a computer can execute.

Examples:

  • C
  • C++
  • Java
  • Python
  • JavaScript

A programming language provides syntax, data types, operators, control structures, functions or procedures, and rules for writing programs.

Syntax

Syntax means the rules for writing valid statements.

int x = 10;

Semantics

Semantics means the meaning of a statement.

x = x + 1;

This means the value of x is increased by 1.

Syntax Semantics
Rules for writing a program Meaning of a program
Concerned with form Concerned with meaning

2. Programming Paradigms and Models

A programming paradigm is a style or approach used for solving problems.

Procedural Programming

The program is organized into procedures or functions.

Example: C.

void display()
{
    printf("Hello");
}

Object-Oriented Programming

The program is organized around objects and classes.

Examples:

  • C++
  • Java

Important concepts:

  • Class
  • Object
  • Encapsulation
  • Abstraction
  • Inheritance
  • Polymorphism

Functional Programming

Computation is expressed using functions.

Examples:

  • Lisp
  • Haskell

Logic Programming

Programs are based on facts and rules.

Example:

  • Prolog

Event-Driven Programming

Program execution is controlled by events such as mouse clicks and keyboard input.

Paradigm Main idea Example
Procedural Procedures/functions C
Object-oriented Objects/classes C++
Functional Functions Haskell
Logic Facts and rules Prolog
Event-driven Events control execution JavaScript

A programming environment provides tools required to develop and execute programs.

Common components:

An IDE commonly combines an editor, compiler/interpreter, debugger, and project management tools.

6. Programming Language Syntax

Syntax describes the structure of valid programs.

Grammar

A grammar defines how valid statements can be formed.

Example:

<digit> ::= 0 | 1 | 2 | ... | 9

BNF

BNF means Backus-Naur Form.

It is a formal notation for describing the syntax of programming languages.

Lexical Structure

Lexical analysis divides source code into tokens.

For:

int total = 10;

tokens include:

Instantiation means creating an object from a class.

Encapsulation means combining data and functions into a single unit and controlling access to the data.

{

};

36. Polymorphism

Polymorphism means one interface can have multiple forms.

Part H – Drawing Algorithms

66. Points and Lines

A 2-D point:

P = (x, y)

A line can be represented using endpoints:

P1 = (x1, y1)
P2 = (x2, y2)

67. DDA Line Drawing Algorithm

DDA means Digital Differential Analyzer.

Given:

(x1, y1)
(x2, y2)

Calculate:

dx = x2 - x1
dy = y2 - y1

Number of steps:

steps = maximum(|dx|, |dy|)

Increments:

x_increment = dx / steps
y_increment = dy / steps

Then repeatedly add the increments.

Example

Given:

P1 = (2, 2)
P2 = (6, 4)

Then:

dx = 4
dy = 2
steps = 4

x_increment = 1
y_increment = 0.5

68. Bresenham Line Drawing Algorithm

Bresenham’s algorithm uses a decision parameter to choose the next pixel.

For a common case where:

0 <= slope <= 1

the initial decision parameter is:

p0 = 2dy - dx

The algorithm chooses between neighboring pixels.

Advantages:

  • Efficient
  • Uses integer arithmetic in the basic formulation
  • Avoids repeated floating-point calculations
DDA Bresenham
Incremental calculations Decision parameter
May use floating-point arithmetic Integer arithmetic in basic form
Simple Efficient

A commonly used initial decision parameter is:

p0 = 1 - r

rx = x-radius

71. Scan-Line Polygon Fill

Basic steps:

  1. Select a horizontal scan line.
  2. Find intersections with polygon edges.
  3. Sort intersections.
  4. Fill between pairs.
  5. Continue with the next scan line.

73. Flood-Fill

Flood fill replaces a connected region having an old color with a new color.

75. Translation

Translation moves an object.

x' = x + tx
y' = y + ty

Homogeneous matrix:

| x' |   | 1  0  tx | | x |
| y' | = | 0  1  ty | | y |

76. Scaling

x' = sx × x
y' = sy × y

Matrix:

| x' |   | sx  0   0 | | x |
| y' | = |  0 sy   0 | | y |
| 1  |   |  0  0   1 | | 1 |

77. Rotation

For counter-clockwise rotation by angle θ:

x' = x cosθ - y sinθ
y' = x sinθ + y cosθ

Matrix:

| x' |   | cosθ  -sinθ  0 | | x |
| y' | = | sinθ   cosθ  0 | | y |
| 1  |   |  0       0    1 | | 1 |

78. Reflection

About x-axis

x' = x
y' = -y

About y-axis

x' = -x
y' = y

About origin

x' = -x
y' = -y

79. Shearing

X-shear

x' = x + shx × y
y' = y

Y-shear

x' = x
y' = y + shy × x

80. Homogeneous Coordinates

A 2-D point:

(x, y)

(x, y, 1)

Homogeneous coordinates allow translation to be represented using matrix multiplication.

81. Composite Transformations

Applying multiple transformations is called a composite transformation.

Example:

Scale → Rotate → Translate

The order matters.

In general:

AB != BA

Therefore transformation matrices are not generally commutative.

86. Window-to-Viewport Transformation

For x:

xv = xvmin + (xw - xwmin) × (xvmax - xvmin) / (xwmax - xwmin)

For y:

yv = yvmin + (yw - ywmin) × (yvmax - yvmin) / (ywmax - ywmin)

where:

Window:
(xwmin, ywmin) to (xwmax, ywmax)

Viewport:
(xvmin, yvmin) to (xvmax, yvmax)

87. Line Clipping

Clipping removes portions of objects outside the viewing region.

Important algorithms:

  • Cohen-Sutherland
  • Liang-Barsky

88. Cohen-Sutherland Algorithm

Cohen-Sutherland uses a 4-bit region code.

The four regions represent:

  • Above
  • Below
  • Right
  • Left

A common coding is:

TOP    = 1000
BOTTOM = 0100
RIGHT  = 0010
LEFT   = 0001

Trivial acceptance

If:

code1 OR code2 = 0000

the line is completely inside.

Trivial rejection

If:

code1 AND code2 != 0000

the line is completely outside in a common outside region.

Otherwise, calculate an intersection and continue.

89. Liang-Barsky Algorithm

Liang-Barsky uses the parametric line:

x = x1 + u(x2 - x1)
y = y1 + u(y2 - y1)

where:

0 <= u <= 1

It uses clipping-boundary inequalities to determine the visible interval.

Cohen-Sutherland Liang-Barsky
Region-code method Parametric method
Uses 4-bit codes Uses parameter limits
Simple concept Efficient for rectangular clipping

Splines are mathematical curves used for smooth shape representation.

Advantages:

  • Smooth curves
  • Compact representation
  • Useful for design and modeling

95. Bézier Curves

A Bézier curve is controlled by control points.

For a cubic Bézier curve:

P(u) =
(1-u)^3 P0
+ 3(1-u)^2u P1
+ 3(1-u)u² P2
+ u³ P3

where:

0 <= u <= 1

Important properties:

  • Starts at P0
  • Ends at P3
  • P1 and P2 control the shape
  • Convex-hull property
  • Affine invariance

96. B-Spline Curves

B-splines use control points and basis functions.

Important properties:

  • Local control
  • Smooth curves
  • Flexible shape control
  • Useful for complex shapes

Part K – Illumination and Rendering

99. Illumination Models

Illumination models describe how light interacts with surfaces.

Important components:

  1. Ambient
  2. Diffuse
  3. Specular

100. Ambient Reflection

Ambient light provides background illumination.

A simplified model:

Iambient = ka × Ia

where:

ka = ambient reflection coefficient
Ia = ambient intensity

101. Diffuse Reflection

Diffuse reflection occurs when light is scattered by a rough surface.

A common model:

Idiffuse = kd × I × max(0, N · L)

where:

kd = diffuse coefficient
I  = light intensity
N  = surface normal
L  = light direction

102. Specular Reflection

Specular reflection produces highlights on shiny surfaces.

A common Phong-style term is proportional to:

ks × I × (R · V)^n

where:

ks = specular coefficient
R  = reflection direction
V  = viewer direction
n  = shininess exponent

103. Polygon Rendering Methods

Important methods:

  • Flat shading
  • Gouraud shading
  • Phong shading

Flat Shading

One intensity is calculated for an entire polygon.

Gouraud Shading

Intensity is calculated at vertices and interpolated across the polygon.

Phong Shading

Normal vectors are interpolated and lighting is calculated more finely across the surface.

Flat Gouraud Phong
One value per polygon Vertex values interpolated Normals interpolated
Simple Smoother Better highlights
Lower computation Medium Higher computation

115. Common Mistakes

Syntax vs Semantics

Syntax   = Form
Semantics = Meaning

Structure vs Union

Structure → separate member storage
Union     → shared storage

Constructor vs Destructor

Constructor → initialization
Destructor  → cleanup

Overloading vs Overriding

Overloading → same name, different parameter list
Overriding  → derived class provides another implementation

Boundary Fill vs Flood Fill

Boundary Fill → boundary color
Flood Fill    → old/interior color

Window vs Viewport

Window   → selected world-coordinate area
Viewport → display-coordinate area

Bézier vs B-Spline

Bézier  → overall control
B-Spline → local control

Parallel vs Perspective

Parallel    → parallel projectors
Perspective → converging projectors
