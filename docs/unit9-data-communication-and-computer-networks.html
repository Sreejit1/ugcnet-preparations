Unit IX – Data Communication and Computer Networks

UGC NET Computer Science and Applications – Paper 2

1. Introduction

Data communication is the exchange of data between two or more devices through a communication medium.

A computer network is a collection of interconnected devices that communicate and share resources.

This unit covers:

  • Data communication fundamentals
  • Signals, bandwidth, throughput and latency
  • Transmission, encoding and modulation
  • Multiplexing and transmission media
  • Errors and error handling
  • LAN, MAN, WAN and wireless networks
  • OSI and TCP/IP models
  • Addressing and switching
  • Framing, flow/error control and multiple access
  • IPv4 and IPv6
  • ARP and routing
  • TCP, UDP and SCTP
  • WWW, DNS and email
  • Network security
  • Mobile technology
  • Cloud computing
  • Internet of Things

2. Components of a Data Communication System

A basic data communication system has five components:

  1. Sender
  2. Receiver
  3. Message
  4. Transmission medium
  5. Protocol

Sender

The device that sends information.

Receiver

The device that receives information.

Message

The information being transmitted.

Examples:

  • Text
  • Image
  • Audio
  • Video
  • File

Transmission Medium

The path through which data travels.

Examples:

  • Twisted-pair cable
  • Coaxial cable
  • Optical fiber
  • Radio waves

Protocol

A set of rules governing communication.

Examples:

  • TCP
  • IP
  • HTTP
  • FTP
  • SMTP

3. Modes of Communication

3.1 Simplex

Communication takes place in only one direction.

Sender ─────────→ Receiver

Example:

  • Traditional television broadcasting

3.2 Half-Duplex

Communication occurs in both directions, but not simultaneously.

A ─────────→ B
A ←───────── B

Example:

  • Walkie-talkie

3.3 Full-Duplex

Communication occurs in both directions simultaneously.

Example:

  • Telephone conversation

Comparison

Mode Direction Simultaneous?
Simplex One direction No
Half-duplex Both directions No
Full-duplex Both directions Yes

4. Analog and Digital Signals

A signal carries information through a communication system.

Analog Signal

An analog signal varies continuously.

Examples:

  • Traditional voice signal
  • Analog radio

Digital Signal

A digital signal uses discrete values.

A common digital representation uses:

0 and 1

Comparison

Analog Digital
Continuous Discrete
More directly affected by accumulated noise Can often be regenerated
Common in traditional analog systems Common in computer communication

5. Periodic Signal

A periodic signal repeats after a fixed interval.

Important characteristics:

  • Amplitude
  • Frequency
  • Period
  • Phase

Amplitude

The maximum magnitude of the signal.

Frequency

Number of cycles per second.

Unit:

Hertz (Hz)

Period

Time for one complete cycle.

f = 1/T

where:

  • f = frequency
  • T = period

Phase

Describes the position of a waveform relative to a reference.

6. Wavelength

Wavelength is the distance travelled by a wave during one cycle.

λ = v/f

where:

  • λ = wavelength
  • v = propagation speed
  • f = frequency

7. Noiseless and Noisy Channels

Noiseless Channel

A theoretical channel in which transmission does not introduce noise errors.

For a noiseless channel, the Nyquist formula gives the maximum theoretical bit rate:

Bit Rate = 2 × Bandwidth × log₂(L)

where L is the number of signal levels.

Noisy Channel

Real channels may contain noise.

The Shannon channel capacity is:

Capacity = Bandwidth × log₂(1 + S/N)

where:

  • S = signal power
  • N = noise power

If S/N is expressed in decibels:

SNR(dB) = 10 × log₁₀(S/N)

UGC NET Point

Nyquist → noiseless channel

Shannon → noisy channel

8. Bandwidth

Bandwidth can refer to the range of frequencies occupied by a signal or supported by a channel.

For a frequency range:

Bandwidth = Highest frequency − Lowest frequency

Example:

If the frequency range is 3 MHz to 5 MHz:

Bandwidth = 2 MHz

9. Throughput

Throughput is the actual rate at which data is successfully transferred.

Example:

A link may have a nominal capacity of 100 Mbps but achieve only 80 Mbps of actual throughput.

Therefore:

Bandwidth/capacity is not necessarily equal to actual throughput.

10. Latency

Latency is the time taken for data to travel through a communication system.

Important components:

  • Processing delay
  • Queuing delay
  • Transmission delay
  • Propagation delay

Transmission Delay

Time needed to put all packet bits onto the link.

Transmission delay = Packet size ÷ Data rate

Propagation Delay

Time required for the signal to travel through the medium.

Propagation delay = Distance ÷ Propagation speed

11. Digital Transmission

Digital transmission communicates information using digital signals.

Important concepts:

  • Line coding
  • Digital-to-digital encoding
  • Pulse-based transmission

Examples of line coding:

  • NRZ
  • Manchester
  • Differential Manchester

12. Analog Transmission

Analog transmission uses an analog carrier signal.

Digital data can be converted to an analog signal using modulation.

Important methods:

  • ASK
  • FSK
  • PSK
  • QAM

13. Data Encoding

Encoding converts data into an appropriate signal representation.

NRZ

NRZ = Non-Return-to-Zero

The signal level remains at a particular level during a bit interval.

Manchester Encoding

There is a transition in the middle of each bit period.

A major advantage is synchronization.

Differential Manchester

Information is represented using transitions and is less dependent on the absolute signal level.

14. Modulation Techniques

ASK

Amplitude Shift Keying

Amplitude of the carrier is changed.

FSK

Frequency Shift Keying

Frequency of the carrier is changed.

PSK

Phase Shift Keying

Phase of the carrier is changed.

QAM

Quadrature Amplitude Modulation

Both amplitude and phase are varied.

Comparison

Technique Main Property Changed
ASK Amplitude
FSK Frequency
PSK Phase
QAM Amplitude + Phase

15. Broadband and Baseband Transmission

Baseband

The signal is transmitted directly over the communication channel without shifting it to a separate carrier frequency.

Baseband is common in many LAN technologies.

Broadband

The available frequency range can support multiple channels or carrier-modulated signals.

Comparison

Baseband Broadband
Direct/baseband signaling Often carrier/modulation based
Common in LANs Common in many wideband systems

Multiplexing allows multiple signals to share a communication medium.

A multiplexer combines signals.

A demultiplexer separates them.

Important techniques:

  • FDM
  • TDM
  • WDM
  • CDM

FDM = Frequency Division Multiplexing

WDM = Wavelength Division Multiplexing

WDM is mainly associated with optical fiber.

Different optical wavelengths carry different signals.

20. Transmission Media

Transmission media are classified into:

Guided Media

Signals travel through a physical path.

Examples:

  • Twisted pair
  • Coaxial cable
  • Optical fiber

Unguided Media

Signals travel through free space.

Examples:

  • Radio
  • Microwave
  • Infrared
  • Satellite

21. Twisted-Pair Cable

Twisted-pair cable contains pairs of insulated copper wires twisted together.

Types:

  • UTP
  • STP

Advantages

  • Low cost
  • Easy installation
  • Widely used

Limitations

  • More susceptible to interference than optical fiber
  • Limited range compared with some fiber systems

22. Coaxial Cable

A coaxial cable contains:

  • Central conductor
  • Insulating layer
  • Shield
  • Outer protective layer

It provides better shielding than ordinary twisted pair.

Applications include:

  • Cable television
  • Broadband systems
  • Older network technologies

23. Optical Fiber

Optical fiber carries information using light.

Main parts:

  • Core
  • Cladding
  • Protective coating

Advantages

  • High bandwidth
  • Low attenuation
  • Resistant to electromagnetic interference
  • Long-distance transmission

Limitations

  • More difficult installation
  • Specialized equipment
  • Can be physically fragile

24. Wireless Media

Examples:

  • Radio
  • Microwave
  • Infrared
  • Satellite

Wireless communication supports mobility and reduces cabling.

25. Transmission Errors

A transmission error occurs when received data differs from transmitted data.

Single-Bit Error

One bit is changed.

Burst Error

Multiple bits in a sequence are affected.

26. Error Detection

Important methods:

  • Parity
  • Checksum
  • CRC

27. Parity

A parity bit is added to a data unit.

Even Parity

The total number of 1s is made even.

Odd Parity

The total number of 1s is made odd.

Parity is simple but cannot detect every possible error pattern.

28. Checksum

A checksum is calculated from a block of data and sent with the data.

The receiver performs a corresponding calculation to detect errors.

29. CRC

CRC = Cyclic Redundancy Check

CRC uses polynomial-style binary division with a generator polynomial.

The remainder becomes the CRC value.

CRC is particularly effective for detecting burst errors.

30. Error Handling

Error handling can use:

  • Error detection
  • Acknowledgements
  • Sequence numbers
  • Timers
  • Retransmissions

Important ARQ methods:

  • Stop-and-Wait ARQ
  • Go-Back-N
  • Selective Repeat

31. Computer Networks

A computer network connects devices so that they can communicate and share resources.

Benefits include:

  • Resource sharing
  • File sharing
  • Communication
  • Centralized services
  • Internet access
  • Distributed applications

32. Network Topologies

Important network topologies:

  • Bus
  • Star
  • Ring
  • Mesh
  • Tree
  • Hybrid

33. Bus Topology

All devices share a common backbone.

A ── B ── C ── D
      Backbone

Advantage

Simple structure.

Limitation

A backbone failure can affect communication for the network.

34. Star Topology

All devices connect to a central device.

       A
       |
B ---- Switch ---- C
       |
       D

Advantages

  • Easy management
  • Easy expansion
  • Failure of one access link generally affects one device

Limitation

Failure of the central device can affect connected devices.

35. Ring Topology

Each node connects to neighboring nodes.

A → B → C → D
↑           ↓
└───────────┘

36. Mesh Topology

Devices have multiple interconnections.

For a full mesh with n devices:

Number of links = n(n − 1) ÷ 2

Advantage

High redundancy.

Disadvantage

Large number of links.

Provides network-to-network delivery.

Functions:

  • Logical addressing
  • Routing

IP

Provides process-to-process communication.

Protocols:

  • TCP
  • UDP
  • SCTP

Functions may include:

  • Segmentation
  • Reassembly

Manages communication sessions.

Functions may include:

  • Session termination

Deals with data representation.

51. Switching Techniques

Important switching techniques:

  • Circuit switching
  • Packet switching
  • Message switching

52. Circuit Switching

A dedicated communication path is established before data transfer.

Phases:

  1. Connection setup
  2. Data transfer
  3. Connection release

Traditional telephone systems are associated with circuit switching.

53. Packet Switching

Data is divided into packets.

Two important approaches:

  • Datagram
  • Virtual circuit

The Internet is based primarily on packet switching.

54. Message Switching

The entire message is stored and forwarded between nodes.

A dedicated end-to-end circuit is not required.

55. Framing

Framing divides a bit stream into frames.

It allows the Data Link layer to identify boundaries between units of transmitted data.

Framing can support:

  • Error detection
  • Addressing
  • Flow control
  • Media access

56. Flow Control

Flow control prevents a sender from overwhelming a receiver.

Important methods:

  • Stop-and-Wait
  • Sliding Window

57. Error Control

Error control provides mechanisms for reliable transmission.

It can use:

  • Acknowledgements
  • Sequence numbers
  • Retransmissions
  • Timers
  • Error detection

58. Sliding Window Protocol

A sender can transmit multiple frames/segments before waiting for acknowledgements, subject to a window.

Advantages:

  • Better channel utilization
  • Higher throughput
  • Less waiting

Important protocols:

  • Go-Back-N
  • Selective Repeat

59. Go-Back-N

If frame 3 is lost:

1 2 3 4 5
    X

The sender may retransmit:

3 4 5

The receiver generally maintains a cumulative acknowledgement scheme.

60. Selective Repeat

If frame 3 is lost:

1 2 3 4 5
    X

Only frame 3 may be retransmitted:

3

It requires more receiver buffering and bookkeeping.

61. HDLC

HDLC = High-Level Data Link Control

HDLC is a bit-oriented Data Link protocol.

A common frame structure is:

Flag | Address | Control | Information | FCS | Flag

FCS means:

Frame Check Sequence

62. Multiple Access

Multiple access protocols control how multiple devices share a common medium.

Important methods:

  • CSMA/CD
  • CSMA/CA
  • Reservation
  • Polling
  • Token passing
  • FDMA
  • TDMA
  • CDMA

63. CSMA/CD

Carrier Sense Multiple Access with Collision Detection

Historically associated with shared-medium half-duplex Ethernet.

Basic idea:

  1. Sense the channel.
  2. Transmit if idle.
  3. Detect collision.
  4. Stop transmission if collision occurs.
  5. Wait using a backoff algorithm.
  6. Retransmit.

Modern switched full-duplex Ethernet normally does not use CSMA/CD.

64. CSMA/CA

Carrier Sense Multiple Access with Collision Avoidance

Commonly associated with wireless LANs.

It attempts to reduce the probability of collisions before transmission.

Associated technology:

IEEE 802.11 Wi-Fi

65. Reservation

Stations reserve transmission opportunities before transmitting.

This can reduce collisions when many devices share a channel.

66. Polling

A central controller gives devices opportunities to transmit.

Advantage

Controlled access.

Limitation

The central controller can become a bottleneck or point of failure.

67. Token Passing

A special control frame called a token circulates among stations.

Only the station holding the token can transmit.

Advantage

Predictable and collision-free medium access.

68. FDMA, TDMA and CDMA

FDMA

Frequency Division Multiple Access

Users receive separate frequency bands.

TDMA

Time Division Multiple Access

Users receive separate time slots.

CDMA

Code Division Multiple Access

Users share frequency/time resources using different codes.

Easy Memory

FDMA → Frequency

TDMA → Time

CDMA → Code

69. Network Devices

Repeater

Regenerates or repeats signals.

Hub

A multiport repeater.

Bridge

Connects network segments at the Data Link layer.

Switch

Usually a multiport bridge that forwards frames using MAC addresses.

Router

Forwards packets between networks.

Gateway

Connects networks or systems and may translate between protocols.

Access Point

Provides wireless network connectivity to stations.

Modem

Performs modulation/demodulation functions for suitable communication links.

70. Backbone Networks

A backbone is a high-capacity network segment connecting smaller networks.

Examples:

  • Campus backbone
  • Enterprise backbone
  • Internet backbone

71. Virtual LAN

VLAN = Virtual Local Area Network

A VLAN logically divides a switched network into separate broadcast domains.

Benefits:

  • Segmentation
  • Easier management
  • Reduced broadcast scope
  • Potential security improvement

72. IPv4 Structure

IPv4 uses:

32-bit addresses

Example:

192.168.1.10

IPv4 addresses are commonly written as four decimal octets.

Each octet ranges from:

0 to 255

73. IPv4 Address Space

IPv4 has:

2^32

possible 32-bit address combinations.

This is approximately:

4.29 billion

addresses, although many are reserved or unavailable for general host assignment.

74. Classful Addressing

Traditional classful addressing used:

77. IPv4 Fragmentation

Fragmentation can occur when an IPv4 packet is larger than the MTU of the outgoing link.

Important fields:

  • Identification
  • Flags
  • Fragment Offset

The destination can reassemble fragments.

Important

IPv4 routers may fragment packets when allowed.

IPv6 routers do not fragment transit packets; fragmentation is handled by the source using an extension header.

78. IPv4 Checksum

IPv4 has a checksum in its base header.

It protects the IPv4 header.

The checksum must be recalculated when relevant header fields change during forwarding.

79. IPv6

IPv6 uses:

128-bit addresses

Example:

IPv6 provides a much larger address space.

IPv6 has:

  • 128-bit addresses
  • Extension headers

81. ARP

ARP = Address Resolution Protocol

ARP maps an IPv4 address to a MAC address on a local network.

Example:

IPv4 address → MAC address

A host can broadcast an ARP request asking which device owns a particular IPv4 address.

Important

ARP is used with IPv4.

IPv6 uses Neighbor Discovery Protocol (NDP) instead of ARP.

82. Direct and Indirect Delivery

Direct Delivery

Source and destination are on the same local network.

Indirect Delivery

Source and destination are on different networks.

The packet is sent to a router/default gateway for forwarding.

85. Link State Routing

Routers build a view of network topology.

Typical steps:

150. Common UGC NET Mistakes

Mistake 1: Bandwidth vs Throughput

Bandwidth/capacity ≠ actual throughput

Mistake 2: Transmission vs Propagation Delay

Transmission delay = Packet size ÷ Data rate

Propagation delay = Distance ÷ Propagation speed

Mistake 3: Nyquist vs Shannon

Nyquist → noiseless

Shannon → noisy

Mistake 4: MAC vs IP

MAC → link-layer address

IP → logical/network-layer address

Mistake 5: ARP vs DNS

ARP → IPv4 address to MAC address

DNS → domain name resolution

Mistake 6: TCP vs UDP

TCP → reliable, connection-oriented

UDP → connectionless, best-effort

Mistake 7: CSMA/CD vs CSMA/CA

CSMA/CD → collision detection, shared Ethernet

CSMA/CA → collision avoidance, Wi-Fi

Mistake 8: FDM vs TDM vs CDM

FDM → Frequency

TDM → Time

CDM → Code

Mistake 9: SMTP vs POP vs IMAP

SMTP → sending/transfer

POP3 → retrieval

IMAP → server-based mailbox access

Mistake 10: SaaS vs PaaS vs IaaS

SaaS → Software

PaaS → Platform

IaaS → Infrastructure
